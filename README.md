# 🤖 ChatGPT Scratch Extension

Bring the power of OpenAI's ChatGPT into Scratch!

This extension allows you to generate AI-powered responses directly inside your Scratch projects using the OpenAI API.

## ✨ Features

- 🤖 Generate text using ChatGPT.
- 💬 Send custom prompts to the AI.
- ⚡ Get responses directly inside Scratch blocks.
- 🎨 Easy to use with Scratch projects.
- 🔌 Powered by the OpenAI API.

## 📦 Installation

1. Download or clone this repository.
2. Make sure `chatgpt.js` is available.
3. Open a Scratch mod or editor that supports custom extensions.
4. Load `chatgpt.js` as an **unsandboxed extension**.
5. Make sure you have a valid OpenAI API key configured.

## 🧩 How to Use

Once installed, you will find a new extension category called **ChatGPT**.

It includes the following block:

`Generate text with prompt: [PROMPT]`

Enter a prompt into the block, and the extension will send it to OpenAI and return the generated response.

### Example

**Prompt:**\
`Tell me a fun fact about space.`

**Response:**\
The Sun makes up about 99.86% of the mass of our solar system!

*Responses are generated by the OpenAI API and may vary.*

## 🔑 API Key Setup

This extension requires an OpenAI API key.

1. Get an API key through the [OpenAI Platform](https://platform.openai.com/api-keys).
2. Configure the key in `chatgpt.js`.
3. Keep your API key private.

**⚠️ Important:** Never upload your API key to GitHub. Anyone who can access the source code could copy and use it. For a public project, use a secure backend to handle API requests instead.

## ⚙️ Requirements

- A Scratch-compatible editor that supports custom extensions.
- Unsandboxed extension support.
- An OpenAI API key.
- Internet connection.
